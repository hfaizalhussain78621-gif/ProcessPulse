# ProcessPulse — Business Process Bottleneck & Operational Analytics Dashboard
**Author:** Faizal Hussain .H

https://processpulse-iyqnqjfxrfwzhfaq2azuyl.streamlit.app/

## Overview
ProcessPulse is an interactive operational analytics and bottleneck-detection dashboard built with Python and Streamlit. It analyzes 300+ multi-stage workflow records across 6 core business processes to identify cycle-time delays, SLA breaches, rework loops, and high-impact root causes.

## Quick Start
1. Install dependencies:
   `pip install -r requirements.txt`
2. Run the dashboard:
   `streamlit run app.py`
